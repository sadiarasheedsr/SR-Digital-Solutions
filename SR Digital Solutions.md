# SR Digital Solutions

## Project Overview

SR Digital Solutions is a modern and responsive company website designed to present digital services in a clean and professional way.

The website focuses on web development, UI design, and responsive design. It provides visitors with information about the company, its services, and ways to get in touch.

## Features

- Responsive navigation bar
- Home section with company introduction
- About section
- Services section
- Contact section
- Contact form
- Email contact link
- LinkedIn link
- Responsive design for different screen sizes
- Smooth scrolling
- Hover effects
- Floating image animation
- Modern cards and buttons
- Animated elements
- Responsive mobile layout
- Footer with copyright information

## Website Sections

### 1. Home

The Home section introduces SR Digital Solutions and presents the company's main focus on web development and UI design.

It includes:
- Welcome message
- Main heading
- Company description
- Get Started button
- Our Services button
- Company image

### 2. About

The About section introduces SR Digital Solutions and explains the company's approach to creating modern, responsive, and user-friendly websites.

### 3. Services

The Services section presents three main services:

- **Web Development**
- **UI Design**
- **Responsive Design**

Each service is displayed inside a separate card with an icon and description.

### 4. Contact

The Contact section allows visitors to get in touch with the company.

It includes:
- Company email
- LinkedIn link
- Name input
- Email input
- Project/message textarea
- Send Message button

### 5. Footer

The footer contains the copyright information:

**© 2026 SR Digital Solutions. All Rights Reserved.**

## How to Run the Project

1. Download or clone the project.
2. Keep all project files in the same folder.
3. Make sure the image file is in the project folder.
4. Open `index.html` in a web browser.

For the best development experience, the project can also be opened using **VS Code with Live Server**.

## Responsive Design

The website is designed to work on:

- Desktop computers
- Laptops
- Tablets
- Mobile phones

CSS media queries are used to adjust the navigation, content, service cards, contact section, and image sizes for smaller screens.

## Design

The website uses:

- A modern purple color theme
- Clean typography
- Rounded cards
- Soft shadows
- Gradient backgrounds
- Hover effects
- Smooth transitions
- Floating animations

The project uses the **Poppins** font from Google Fonts.
